# 디자인 수정본 적용

첨부 디자인의 큰 제목, 상단 완료 목록 링크, 밑줄 탭, 전체보기/진행 중 버튼, 할 일 카드와 별도 통계 화면을 반영했습니다. 사진의 예시 작업은 자동으로 넣지 않습니다. 첫 접속은 빈 목록으로 시작합니다.

기존 localStorage 키(zero100-week3-tasks)는 유지했습니다. 동일한 브라우저와 주소로 실행하면 기존 작업을 읽습니다.

## 적용 순서

1. 실행 중인 개발 서버에서 Ctrl+C를 누릅니다.
2. 기존 프로젝트를 백업합니다.
3. ZIP 안 zero100-week3 폴더의 내용을 기존 프로젝트 폴더에 복사합니다. 특히 src 폴더를 통째로 교체합니다. .git 폴더는 건드리지 않습니다.
4. package.json이 있는 위치에서 npm.cmd ci를 실행합니다.
5. npm.cmd run dev로 실행합니다.

## 페이지

- / : 전체 할 일 (참고 이미지의 기본 선택)
- /active : 진행 중인 할 일
- /completed : 완료 목록
- /stats : 별도 통계 탭
- /all : 이전 주소 호환을 위해 /로 이동

목록에서는 남은 개수를 표시하고 통계 탭에서는 전체/진행 중/완료 및 완료율을 표시합니다. 수정·저장·취소 문구는 참고 화면에 맞춰 한글로 변경했습니다.
